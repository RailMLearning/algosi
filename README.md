# Бинарные деревья поиска

Домашняя работа по теме BST и AVL. Решения на C++17.

[Задачи в Яндекс Контесте](https://contest.yandex.ru/contest/100803/problems/)

- `A.cpp` — BST без балансировки: вставка, удаление, поиск, высота и обход.
- `B.cpp` — левые и правые повороты дерева по командам.
- `C.cpp` — AVL-дерево со вставкой.
- `D.cpp` — AVL-дерево со вставкой, удалением и поиском соседей.

При удалении узла с двумя детьми используется минимум правого поддерева.
В AVL высоты хранятся в вершинах и пересчитываются после изменений.
В задаче D команды `next` и `prev` включают равенство.

Каждый файл — отдельная программа. Например, для задачи D:

```sh
g++ -std=c++17 -O2 -Wall -Wextra D.cpp -o D
```
